# The Clear Pill — failed Revelation animation

Open `index.html` in a modern browser. The 24-second loop begins with an oppressive demand for a final philosophical answer. A transparent pill marked “NOW” interrupts the question, wipes the screen clean, and releases a bright collage of immediate, ordinary life.

The art direction deliberately rejects all four suit languages. It uses no suit emblems, lore, named philosophy, solemn engraving, cosmic depth, ceremonial flame, utopian monument, or martial imagery. Its materials are contemporary and unserious: transit paper, condensation, citrus, a sneaker, keys, pool light, soap bubbles, and an actual live clock.

Controls:

- Use the bottom-right button or `Space` to pause and continue.
- Use “Again” or `R` to restart the sequence.
- The scene becomes a still “ordinary afternoon” composition when the operating system requests reduced motion.

The animation uses only original HTML, CSS, SVG noise, and JavaScript. It has no external runtime dependencies.
